# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0-pre-alpha] - 2026-01-06

### Pre-Alpha Release

This is the first public Pre-Alpha release of Campus Connect, representing the initial MVP with core functionality for cart tracking and management.

## [1.0.0] - 2026-01-06

### Added
- Initial release of Campus Connect
- Student Dashboard with real-time cart tracking
- Admin Dashboard with cart control features
- Interactive map using Leaflet
- ETA calculation system
- Multi-cart support (Red Cart-1 and Blue Cart-1)
- Home screen with navigation
- Route B with 5 stops (Main Gate, Library, A1 Cafe, OBC Cafe, Engineering Block 1)
- Cart movement simulation with direction reversal
- Stop wait time implementation
- Unified theme system with CSS variables
- Responsive design for mobile and desktop
- Batch scripts for easy installation and startup

### Features
- Real-time cart location updates
- ETA calculation considering cart direction
- Cart status management (moving, stopped, idle)
- Route reset functionality
- Cart selection dropdown in both dashboards
- Beautiful gradient UI design
- MMDU campus map integration

### Technical
- React 18 frontend with Vite
- Node.js/Express backend
- OOP-based cart management
- RESTful API architecture
- CSS theme system with variables
